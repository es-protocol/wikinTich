📝 How to get a Request ID:
  1. Start your main Tutor-Link app: npm run dev
  2. Go to Super Admin Dashboard
  3. Look at "Tutoring Requests" section
  4. Copy any request ID from the list

🔌 Available API Endpoints

GET /health - Service health check
GET /stats - Service statistics
POST /match - Get tutor recommendations
POST /match/batch - Batch matching
GET /tutor/:id - Get tutor details
GET /tutor/:id/availability - Check tutor availability
